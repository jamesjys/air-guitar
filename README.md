# Air Guitar 🎸

An experimental interactive project created as part of my early exploration of programming and AI-assisted development.

## About

This project explores the idea of creating an interactive "air guitar" experience using software.

## Features

## Features

**Real-Time Hand Tracking** – Leverages advanced computer vision to precisely track hand landmarks via your webcam with zero latency.
**AI Chord Classification** – Automatically maps your left-hand finger patterns to essential guitar chords (e.g., E, Am, C, G, D, Em).
**Dynamic Strumming Detection** – Analyzes your right-hand wrist movements to trigger realistic up-strums, down-strums, and volume accents.
**Interactive String Overlay** – Displays digital, responsive guitar strings on the camera feed that vibrate instantly when plucked or strummed.
**Privacy-First Processing** – Runs entirely locally in the browser or device; no video recording or data tracking ever leaves your machine.

## Development

This project was developed with assistance from AI coding tools.

Rather than treating the generated code as a finished solution, I use the project to learn about the code structure, test functionality, identify bugs, and understand how different components work together.
